```bash
docker compose up --build
```

2. Open Swagger:

http://localhost:${{ values.port }}/swagger

## Environment Variables

- DB_HOST
- DB_USER
- DB_PASSWORD
- DB_NAME

The API builds `ConnectionStrings:DefaultConnection` at startup from these values.
